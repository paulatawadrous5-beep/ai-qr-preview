Printing tips that actually matter

  • Size: at least 2 × 2 cm for table tents scanned at arm's length; 5 cm+ for posters scanned from meters away.
  • Contrast: dark code on a light background. Fancy low-contrast designs look great and scan terribly — Smart QR's auto-repair catches this before you print.
  • Quiet zone: leave white space around the code (at least the width of one module on each side); don't let text or borders crowd it.
  • Test the real print: scan the actual printed tent with two different phones (iPhone + Android) before printing a hundred of them.
  • Add a call to action: a frame that says "SCAN FOR MENU" gets far more scans than a bare code — people need the nudge.

Why a link beats a static menu image

A QR code that points to your menu page keeps working when the menu changes: new seasonal dishes, sold-out items, price updates — edit the page and every printed code across your restaurant shows the latest version instantly. Reprinting table tents every time the chef changes a special gets expensive fast; one good print lasts years.

Tip: put the same menu QR code on your receipts, takeaway bags and storefront window — it keeps working for delivery and takeaway customers too, long after they've left the table.

Can I update my menu without reprinting the QR code?

Yes — if your QR code points to a menu page link (your website, Google Business profile, or a hosted PDF link you can replace), updating the page updates what diners see. The printed QR code never changes.

How big should a printed menu QR code be?

At least 2 x 2 cm (about 0.8 inches) for table tents scanned at arm's length. For window posters or wall signs scanned from a few meters away, go 5 cm or larger. Always test-scan the actual print before committing to a full run.

Should the QR code match my restaurant branding?

Absolutely — a branded code with your colors and logo gets scanned more than a generic black square. Just keep contrast high (dark code on light background) so every phone scans it reliably. Smart QR checks contrast and scanability automatically.
